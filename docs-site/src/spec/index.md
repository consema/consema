# 规范

RFC 是 Consema 语言无关规范的权威载体：每个 RFC 定义一个格式家族、协议或政策的冻结契约，设计与实现语言无关（语言中立同等地位原则）。

- **[RFC 0015：CLI 机器协议与 batch apply v1](rfcs/0015-cli-machine-protocol-and-batch-apply-v1.md)**：`consema` CLI 的机器可读协议——envelope、exit-code 分类、batch-plan/batch-result manifest、检测与修复语义（Status: Implemented in 0.12.0）。
- **[RFC 0020：1.0 兼容与支持政策 v1](rfcs/0020-compatibility-and-support-policy-v1.md)**：1.0 兼容与支持政策的规范性定义，自 `1.0.0` 起约束所有发布（Status: Accepted，2026-08-10 于 0.19.0 接受）。
- **[RFC 0001–0016 全清单](rfc-index.md)**：全部十六个 RFC 的编号、标题、状态与本页/权威文件索引。
